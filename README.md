## Descripción
Este repositorio contiene la implementación experimental del estudio sobre estrategias de aprendizaje por refuerzo, abordando el dilema de exploración y explotación en entornos complejos de toma de decisiones.

## Estructura

- **docs/**: incluye el informe documental de la práctica.
- **main.ipynb**: Notebook que permite moverse entre los distintos notebooks del estudio.
- **P2_MonteCarlo.ipynb** : ejercicio 2a, construcción de un agente de Gimnasium que implemente el algoritmo de MonteCarlo.
- **P2_EstudioAlgoritmos.ipynb** : ejercicio 2b, estudio comparativo entre distintos algoritmos estudiados.

## Tecnologías Utilizadas
- **Lenguaje:** Python
- **Librerías:**

  - Torch
  - Librerías estándar python (numpy, pandas, matplotlib)
